# Raw Dataset Directory

The raw dataset `default of credit card clients.xls` is sourced from the UCI Machine Learning Repository (Yeh & Lien, 2009):
- **URL:** https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- **License:** CC BY 4.0

The automated pipeline (`run_all.py` / `src/data_loader.py`) will automatically download, unpack, and verify this file if it is not present.
